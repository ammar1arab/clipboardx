# Change summary

Establish the requested range: working tree, staged files, branch against its real base, or a named PR. Read the diff and relevant commits rather than relying on memory or a branch name.

Write a concise summary of the problem, change, verification, and remaining risk. Include a root cause only when the evidence supports one. Name touched areas accurately; do not claim tests or runtime checks that were not run.

Return copyable text. Drafting a summary does not itself authorize a commit, PR, or message to another person.
